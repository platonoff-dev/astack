# Decision

Use this playbook when a material human choice blocks correctness, scope, risk,
authorization, or the next technical route.

## Work

1. State one concrete question, who can answer it, and which work it blocks.
2. Gather only the evidence needed to make the choice understandable. Separate
   facts, assumptions, and consequences.
3. Give a recommendation when the evidence supports one. Present only distinct
   options and say what each changes in behavior, cost, risk, or delivery.
4. Finish all independent safe work before asking. Show the complete decision
   needed; do not spread one choice across repeated approval questions.
5. Record the answer and its source in the existing brief. Remove the resolved
   question and route the same task onward.

## Leave the playbook

Route to the playbook the answer enables. Route to `investigation` if the owner
asks for missing technical evidence. Route to `split` if the decision creates
independent outcomes. If no answer is available, retain the blocker and stop
without inventing policy.

The decision itself does not authorize publication, deployment, tracker edits,
or other external changes unless the answer explicitly grants that scope.
